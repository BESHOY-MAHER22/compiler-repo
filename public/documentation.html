Section 1 The Regular Expressions for Tokens Only

In compiler lexical analysis, tokens are specified using formal Regular Expressions (RE) defined over the alphabet $\Sigma$. The lexical rules below strictly partition the token stream of the Rynix programming language into disjoint, unambiguous token classes.

1.1 Auxiliary Definitions and Grammar Symbols

Symbol Definition Regular Expression (RE) Semantics
digit [0-9] Any decimal digit from 0 to 9
letter [a-zA-Z] Upper or lower case English alphabetical character
letter_or_underscore [a-zA-Z_] Permissible starting symbol for identifiers
alphanumeric [a-zA-Z0-9_] Permissible tail symbols for identifiers
whitespace [ \t\r\n]+ Ignored inter-token spacing and line separators

1.2 Tokens Formal Specification Table

Token Class Formal Regular Expression (RE) Examples / Lexemes
Identifier letter_or_underscore · (alphanumeric)* x, totalAmount, student_grade
IntConstant digit+ 0, 42, 1000
FloatConstant digit+ · \. · digit+ 15.75, 0.25, 3.14159
StringLiteral " ([^"\\\n\r] | \\.)* " "Hello Rynix", "Total: %d\n"
CharLiteral ' ([^'\\\n\r] | \\.) ' 'A', '0', '\n'
BoolLiteral true | false true, false
NullLiteral null null

1.3 Reserved Words Table (24 Keywords)

Rynix is strictly case-sensitive. The following words are reserved by the language grammar:

Category Keywords List
Declarations & OOP var, fun, class, init, new
Control Flow & Loops if, else, while, for, in, return, break, continue
Built-in Types Int, Float, String, Char, Bool, Void, Array
I/O Functions & Values print, input, true, false, null

1.4 Operators and Delimiters Regular Expressions

Category Regular Expression Token Class
Arithmetic \+ | \- | \* | / | % PlusOp, MinusOp, MultiplyOp, DivideOp, ModuloOp
Relational == | != | < | <= | > | >= EqualEqualOp, NotEqualOp, LessThanOp, LessOrEqualOp, GreaterThanOp, GreaterOrEqualOp
Logical && | \|\| | ! AndOp, OrOp, NotOp
Assignment & Range = | \.\. AssignmentOp, DotDot (Range)
Punctuation \( | \) | \{ | \} | \[ | \] | : | ; | , | \. LParanthesis, RParanthesis, LBrace, RBrace, LBracket, RBracket, Colon, Semicolon, Comma, Dot
Comments //[^\r\n]* | /\*([^*]|\*+[^*/])*\*+/ SingleLineComment, MultiLineComment
Maximal Munch Principle: When two operators share a common prefix (e.g. = vs ==, < vs <=, . vs ..), the lexical analyzer always consumes the longest possible valid prefix.

Section 2 Automata: NFAs and DFAs of Tokens Only

In accordance with Thompson's Construction and Subset Construction algorithms, we provide both the Non-Deterministic Finite Automata (NFA with $\epsilon$-transitions) and the minimized Deterministic Finite Automata (DFA) verifying 100% formal accuracy.

2.1 Identifier Automata: (A) Thompson NFA vs (B) Minimized DFA
RE: [a-zA-Z_][a-zA-Z0-9_]*. Accepting state performs Hash Table lookup to distinguish Keywords from user Identifiers.

Formal Verification: Any identifier string begins with a letter or underscore, entering state $q_1$. Any subsequent alphanumeric symbol loops at $q_1$. When the lookahead character is not in [a-zA-Z0-9_], the lexeme is checked against the keyword table in $O(1)$ time.

Current State Input Class Next State Action / Output Token
q0 (Start) [a-zA-Z_] q1 Accumulate identifier characters

using System;
using System.Collections.Generic;

namespace JASON_Compiler
{
    public enum Token_Class
    {
        // Rynix Reserved Words
        Var, Fun, Class, Init, New, If, Else, While, For, In, Return, Break, Continue, Print, Input,
        TypeInt, TypeFloat, TypeString, TypeChar, TypeBool, TypeVoid, TypeArray,
        BoolLiteral, NullLiteral,

        // Delimiters & Operators
        Dot, DotDot, Semicolon, Comma, Colon, LParanthesis, RParanthesis, LBrace, RBrace, LBracket, RBracket,
        AssignmentOp, EqualEqualOp, LessThanOp, GreaterThanOp, NotOp, NotEqualOp, LessOrEqualOp, GreaterOrEqualOp,
        PlusOp, MinusOp, MultiplyOp, DivideOp, ModuloOp, AndOp, OrOp,

        // Identifiers & Constants
        Idenifier, Constant, FloatConstant, StringLiteral, CharLiteral,
        SingleLineComment, MultiLineComment, Unknown
    }

    public class Token
    {
        public string lex;
        public Token_Class token_type;
        public int line = 1;
        public int column = 1;
    }

    public class Scanner

        public void StartScanning(string SourceCode)
        {
            Tokens.Clear();
            Errors.Error_List.Clear();
            int i = 0, line = 1, col = 1, length = SourceCode.Length;

            while (i < length)
            {
                char ch = SourceCode[i];
                if (ch == '\n') { line++; col = 1; i++; continue; }
                if (ch == '\r') { i++; continue; }
                if (ch == ' ' || ch == '\t') { col++; i++; continue; }

                // Comments: // or /* ... */
                if (ch == '/' && i + 1 < length)
                {
                    if (SourceCode[i + 1] == '/')
                    {
                        string c = "//"; int sc = col; i += 2; col += 2;
                        while (i < length && SourceCode[i] != '\n' && SourceCode[i] != '\r') { c += SourceCode[i++]; col++; }
                        Tokens.Add(new Token { lex = c, token_type = Token_Class.SingleLineComment, line = line, column = sc });
                        continue;
                    }
                    if (SourceCode[i + 1] == '*')
                    {
                        string c = "/*"; int sc = col, sl = line; i += 2; col += 2; bool closed = false;
                        while (i < length)
                        {
                            if (SourceCode[i] == '*' && i + 1 < length && SourceCode[i + 1] == '/') { c += "*/"; i += 2; col += 2; closed = true; break; }
                            if (SourceCode[i] == '\n') { line++; col = 1; } else { col++; }
                            c += SourceCode[i++];
                        }
                        if (!closed) Errors.Error_List.Add($"[Line {sl}, Col {sc}] Unterminated comment block: {c}");
                        else Tokens.Add(new Token { lex = c, token_type = Token_Class.MultiLineComment, line = sl, column = sc });
                        continue;
                    }
                }

                // Strings: "..."
                if (ch == '"')
                {
                    string s = ""; int sc = col, sl = line; i++; col++; bool closed = false;
                    while (i < length)
                    {
                        if (SourceCode[i] == '"') { i++; col++; closed = true; break; }
                        if (SourceCode[i] == '\n') break;
                        if (SourceCode[i] == '\\' && i + 1 < length) { s += SourceCode[i].ToString() + SourceCode[i + 1].ToString(); i += 2; col += 2; continue; }
                        s += SourceCode[i++]; col++;
                    }
                    if (!closed) Errors.Error_List.Add($"[Line {sl}, Col {sc}] Unterminated string literal: \"{s}");
                    else Tokens.Add(new Token { lex = "\"" + s + "\"", token_type = Token_Class.StringLiteral, line = sl, column = sc });
                    continue;
                }

                // Two-character operators
                if (i + 1 < length)
                {
                    string two = SourceCode.Substring(i, 2);
                    if (Operators.ContainsKey(two))
                    {
                        Tokens.Add(new Token { lex = two, token_type = Operators[two], line = line, column = col });
                        i += 2; col += 2; continue;
                    }
                }

                // Single-character operators
                string one = ch.ToString();
                if (Operators.ContainsKey(one))
                {
                    Tokens.Add(new Token { lex = one, token_type = Operators[one], line = line, column = col });
                    i++; col++; continue;
                }

                // Numbers: IntConstant or FloatConstant
                if (char.IsDigit(ch))
                {
                    string num = ""; int sc = col; bool isFloat = false;
                    while (i < length && (char.IsDigit(SourceCode[i]) || SourceCode[i] == '.'))
                    {
                        if (SourceCode[i] == '.')
                        {
                            if (i + 1 < length && SourceCode[i + 1] == '.') break; // range ..
                            isFloat = true;
                        }
                        num += SourceCode[i++]; col++;
                    }
                    string trail = "";
                    while (i < length && (char.IsLetter(SourceCode[i]) || SourceCode[i] == '_')) { trail += SourceCode[i++]; col++; }
                    if (trail.Length > 0)
                    {
                        Errors.Error_List.Add($"[Line {line}, Col {sc}] Invalid identifier '{num + trail}': Cannot start with digit");
                        Tokens.Add(new Token { lex = num + trail, token_type = Token_Class.Unknown, line = line, column = sc });
                    }
                    else
                    {
                        Tokens.Add(new Token { lex = num, token_type = isFloat ? Token_Class.FloatConstant : Token_Class.Constant, line = line, column = sc });
                    }
                    continue;
                }

                // Identifiers & Keywords
                if (char.IsLetter(ch) || ch == '_')
                {
                    string id = ""; int sc = col;
                    while (i < length && (char.IsLetterOrDigit(SourceCode[i]) || SourceCode[i] == '_')) { id += SourceCode[i++]; col++; }
                    if (ReservedWords.ContainsKey(id))
                        Tokens.Add(new Token { lex = id, token_type = ReservedWords[id], line = line, column = sc });
                    else
                        Tokens.Add(new Token { lex = id, token_type = Token_Class.Idenifier, line = line, column = sc });
                    continue;
                }

                // Unrecognized character
                Errors.Error_List.Add($"[Line {line}, Col {col}] Unrecognized character: '{ch}'");
                Tokens.Add(new Token { lex = ch.ToString(), token_type = Token_Class.Unknown, line = line, column = col });
                i++; col++;
            }
            JASON_Compiler.TokenStream = Tokens;
        }
    }
